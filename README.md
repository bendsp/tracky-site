# Tracky site

The public landing page for Tracky, a local-first iPhone app for noticing where
your time goes and tracking anything that matters to you.

## Development

Requires Node.js 22 or newer.

```bash
npm install
npm run dev
```

Useful checks:

```bash
npm test
npm run build
```

## Deployment

The site is deployed as a standard Next.js service on Railway and served at
[tracky.desprets.net](https://tracky.desprets.net).

The app icon used by the site is the native compiled PNG produced from
Tracky's Icon Composer project, not a separate web recreation.
